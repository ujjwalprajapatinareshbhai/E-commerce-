# E-Commerce Sales Dashboard – Power BI & SQL Project

This project is an interactive E-Commerce Sales Dashboard developed using Power BI and SQL to analyze sales performance, customer behavior, product demand, and revenue trends. The dashboard provides business insights through dynamic visualizations and interactive filters that help track overall sales growth and operational performance.

## Key Features

* Total Revenue, Orders, Customers, and Average Order Value KPIs
* Monthly Revenue Trend Analysis
* Monthly Orders Trend Visualization
* Revenue Analysis by City
* Revenue Distribution by Product Category
* Top Selling Products Analysis
* Customer Location Insights using Map Visualization
* Interactive Slicers for City, Category, and Month Filtering
* Clean and Professional Dashboard UI Design

## Tools & Technologies Used

* SQL
* Power BI
* Power Query
* DAX (Data Analysis Expressions)
* Excel / CSV Dataset

## Dashboard Insights

* Monthly sales and order performance trends
* Highest revenue-generating cities
* Most profitable product categories
* Top-selling products by order volume
* Customer distribution across locations
* Average order value and customer purchase behavior

## Project Workflow

1. Data extraction and querying using SQL
2. Data cleaning and transformation using Power Query
3. Data modeling and relationship creation
4. KPI and calculated measure creation using DAX
5. Dashboard development and visualization in Power BI

## Project Goal

The objective of this project is to demonstrate practical business intelligence and data analytics skills by transforming raw sales data into meaningful insights using SQL and Power BI. This dashboard helps businesses monitor sales performance, identify growth opportunities, and support data-driven decision-making.
